# Flashcard Quiz App

This is a simple Flashcard Quiz App built using HTML, CSS, and JavaScript.

## Features
- Show Question and Answer
- Next and Previous Flashcards
- Add Flashcards
- Edit Flashcards
- Delete Flashcards
- Local Storage Support

## Technologies Used
- HTML
- CSS
- JavaScript
